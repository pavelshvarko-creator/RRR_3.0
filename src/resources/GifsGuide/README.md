# GifsGuide

Гифки для всплывающего превью при наведении на кнопку/блок в окне гайда
(`src/js/guide/GuideApp.tsx`). Каждый файл — просто `<ключ>.gif`, без
дополнительной регистрации в коде: если файла для блока ещё нет, гайд молча
не показывает попап для него (никакой ошибки не будет).

Ожидаемые имена файлов (по одному на блок):

- `9x16.gif`
- `4x3.gif`
- `1x1.gif`
- `16x9.gif`
- `ctrl.gif`
- `collect.gif`
- `render.gif`
- `en.gif`
