# Как выпускать обновления RRR

Коллеги ставят панель **один раз** через `.zxp`-файл. После этого при каждом
запуске After Effects панель сама проверяет GitHub на новую версию и, если
находит — тихо скачивает и устанавливает её (плюс кнопка «Обновить» в окне
гайда делает то же самое по требованию, в любой момент). Поэтому для новых
версий пересылать и переустанавливать `.zxp` коллегам **не нужно** — он нужен
только для самой первой установки у нового человека.

## Каждый раз, когда нужно выпустить обновление

1. Внеси нужные правки в код (или попроси меня об этом).
2. Подними номер версии в `package.json`, поле `"version"` (например `2.0.2` → `2.0.3`).
3. Собери проект:
   ```
   yarn build
   ```
4. Собери zip для автообновления:
   ```
   yarn release-zip
   ```
   Появится файл `dist/release/RRR_<версия>.zip`.
5. Опубликуй релиз на GitHub (замени `<версия>` на реальный номер, например `2.0.3`):
   ```
   gh release create v<версия> "dist/release/RRR_<версия>.zip" --title "v<версия>" --notes "что изменилось"
   ```

Готово. У всех коллег, кто уже поставил панель, при следующем запуске AE (или
по кнопке «Обновить» в окне гайда) новая версия подтянется сама.

## Если нужно собрать установочный .zxp для НОВОГО коллеги

Нужно только для тех, у кого панели ещё нет вообще (первая установка).

1. Пункты 1–3 выше (правки, версия, `yarn build`).
2. Собери и подпиши `.zxp`. На этой машине нужно временно добавить путь к
   `ZXPSignCmd` в PATH перед сборкой (в PowerShell):
   ```
   $env:Path = "C:\Vrabote\VScode\RRR-CEP\node_modules\vite-cep-plugin\lib\bin;" + $env:Path
   yarn zxp
   ```
   Файл появится в `dist/zxp/com.rrr.panel.zxp`.
3. Отправь коллеге этот файл. Ему нужно один раз установить бесплатную
   программу **ZXP Installer** (или Anastasiy's Extension Manager) — после
   этого `.zxp`-файлы открываются и устанавливаются просто двойным кликом,
   без ручной правки реестра.

## Как проверить, что всё сработало

- Открой страницу релизов: https://github.com/pavelshvarko-creator/RRR/releases —
  там должен быть релиз с нужным номером версии и приложенным `.zip`.
- В самой панели: кружок Info → окно гайда → кнопка «Обновить» — должно либо
  написать, что версия уже последняя, либо скачать новую и попросить
  перезапустить AE.
